# 澄码 0.1.30

本版整合任务工作台、执行与恢复、代码审查、桌面草稿及权限管理等已完成更新。

## 主要更新

- **任务中心**：从目标建立任务，管理执行步骤、验收证据和交付产物；支持项目筛选、搜索、状态筛选和分页读取。
- **独立工作区与审查**：使用 Git worktree 隔离任务改动，执行补丁预检、差异审查和逐行反馈，并保留来源项目中已有的修改。
- **执行控制**：发送队列、暂停与继续、再次执行前确认，以及子任务的只读查看。遇到断线或结果不明时先核对原生状态，避免客户端自动重复提交。
- **恢复与诊断**：保存任务、聊天和浏览位置；补充连接、模型连通性、长任务及恢复过程的诊断信息。
- **桌面草稿**：本机加密保存草稿，支持切换页面、重开窗口和多窗口冲突处理；附件需要重新添加，敏感凭据不作为草稿保存。
- **查找与界面**：历史会话和文件行搜索、按需加载功能面板，优化大量任务读取和移动端操作。
- **权限与设备**：显式服务端审批、配对设备权限范围及审计；远程访问保持主动开启并使用认证连接。
- **导航修复**：创建或导入项目的迟到响应不再覆盖之后选择的页面和输入；图片会话创建后若用户已切换操作，不再继续提交过期的生成请求。
- **发布验证修正**：Windows 安装包验证覆盖全部按需加载脚本和样式，并逐项比对构建内容。

## 安装与已知边界

- macOS 安装包面向 Apple Silicon，要求 macOS 26 或更高版本；使用本地 ad-hoc 签名，尚未提供 Developer ID 签名或 Apple 公证。
- Windows 安装包面向 Windows 10 / 11 x64，尚未通过 Authenticode 签名；跨平台构建及包内资源检查不替代 Windows 实机安装验收。
- 客户端固定使用 OpenCode SDK 2.0.26；Mac 包沿用已验证的原生内核 2.0.25，Windows 包内置原生内核 2.0.26。
- 既往偶发恢复及首次引导加载等待超时尚未确认根因；本次最终隔离验收通过，不代表已永久消除这些情况。首次启动若出现 macOS 钥匙串提示，需由用户手动处理。
- 升级前保存草稿并备份资料，退出应用后覆盖安装；无需删除聊天、配置或模型账户。

本仓库仅发布安装包、更新清单、校验信息与公开说明，不包含开发仓库、个人资料或凭据。
